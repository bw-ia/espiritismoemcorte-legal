Política de Privacidade

Última atualização: 13/10/2026

O aplicativo "Espiritismo em Corte" é uma ferramenta interna, usada exclusivamente pelo dono do canal Espiritismo em Corte. Não é oferecido a outros usuários nem ao público. O app usa os Serviços de API do YouTube (YouTube Data API v3 e YouTube Analytics API).

Dados acessados

  • Informações do canal do próprio dono (nome, ID, estatísticas).
  • Vídeos, títulos, descrições, tags e playlists do canal.
  • Relatórios do YouTube Analytics do canal (visualizações, retenção, origem do tráfego, inscritos).

Finalidade

Os dados são usados apenas para enviar vídeos ao canal, editar títulos, descrições, tags e playlists dos vídeos do canal e analisar o desempenho para planejar novos conteúdos. Toda alteração é aprovada pelo dono do canal.

Compartilhamento

Não compartilhamos, vendemos nem transferimos dados a terceiros, e não os combinamos com dados de outros usuários.

Armazenamento e segurança

O token de acesso OAuth é armazenado de forma segura e privada, com acesso restrito, e nunca é publicado. Dados do Analytics são guardados apenas pelo tempo necessário para a análise.

Revogação

O acesso pode ser revogado a qualquer momento em https://myaccount.google.com/permissions. Também é possível pedir a exclusão dos dados armazenados pelo contato abaixo.

YouTube e Google

Ao usar este app você também está sujeito aos Termos de Serviço do YouTube e à Política de Privacidade do Google. Este app segue os Termos dos Serviços de API do YouTube.

Privacy Policy

Last updated: October 13, 2026

"Espiritismo em Corte" is a private internal tool used exclusively by the owner of the Espiritismo em Corte YouTube channel. It is not offered to other users or the public. The app uses YouTube API Services (YouTube Data API v3 and YouTube Analytics API).

Data accessed

  • The owner's own channel information (name, ID, statistics).
  • The channel's videos, titles, descriptions, tags and playlists.
  • YouTube Analytics reports for the channel (views, retention, traffic sources, subscribers).

Purpose

Data is used only to upload videos to the channel, edit titles, descriptions, tags and playlists of the channel's videos, and analyze performance to plan new content. Every change is approved by the channel owner.

Sharing

We do not share, sell or transfer data to third parties, nor combine it with other users' data.

Storage and security

The OAuth access token is stored securely and privately with restricted access and is never published. Analytics data is kept only as long as needed for analysis.

Revocation

Access can be revoked at any time at https://myaccount.google.com/permissions. You may also request deletion of stored data via the contact below.

YouTube and Google

By using this app you are also bound by the YouTube Terms of Service and the Google Privacy Policy. This app complies with the YouTube API Services Terms of Service.
